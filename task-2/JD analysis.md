##Job Description Analysis

### JD1: Software Engineer – Microsoft, Hyderabad

**Key skills identified:**
- Programming in C, C++, C#, Java, JavaScript, or Python.
- Data structures, algorithms, and software development.
- REST API development and Git workflows.
- Unit testing, software quality, and cloud-based services.

**Curriculum alignment:** The existing curriculum covers programming, Data Structures, Algorithms, DBMS, Operating Systems, and Computer Networks.

**Identified gaps:** Practical exposure to Git-based collaboration, automated testing, CI/CD, and production-oriented API development is not clearly reflected in the listed course titles.

**Recommended improvement:** Update Software Engineering, Web Technologies, and Industry Coding Practice to include version control, REST APIs, unit testing, code reviews, and continuous integration.

### JD2: Systems Software Engineer, AI and Cloud – NVIDIA

**Key skills identified:**
- Python and JavaScript programming.
- Data structures, algorithms, and software design.
- Basic C++ programming.
- Cloud-native development and Kubernetes.
- LLM inference frameworks, including vLLM and NVIDIA Triton Inference Server.
- Scalable API design and AI application development.

**Curriculum alignment:** The existing curriculum includes programming, Data Structures and Algorithms, Machine Learning, Cloud Computing, and Big Data Systems.

**Identified gaps:** Advanced cloud deployment, container orchestration, LLM inference, and production-oriented AI application development are not explicitly established by the course titles alone.

**Recommended improvement:** Strengthen Cloud Computing with Docker and Kubernetes labs, introduce LLM fundamentals in Machine Learning, and add a dedicated LLM Applications and Evaluation course.

### JD3: Software Engineer – Graduates 2026, Zycus

**Key skills identified:**
- AI-assisted coding, debugging, testing, and documentation.
- Prompt engineering and responsible use of AI development tools.
- Backend development and REST APIs.
- Databases, application integration, and maintainable code.
- Collaboration and modern software development practices.

**Curriculum alignment:** The existing curriculum provides foundations through Object-Oriented Programming, DBMS, Software Engineering, Web Technologies, and Industry Coding Practice.

**Identified gaps:** Structured training in AI-assisted software development, output verification, prompt design, and evaluating AI-generated code is not explicitly identified in the existing course titles.

**Recommended improvement:** Introduce an AI-Assisted Engineering Lab in Semester V, following Responsible AI and Technology Ethics in Semester IV. Students should practise generating code, writing tests, identifying AI errors, documenting their use of AI, and reviewing code before accepting it.

### Cross-JD Findings

The three job descriptions indicate that core computer science knowledge remains important, but employers also value practical engineering skills and the ability to apply modern development tools.

| Skill Area | Existing Curriculum | Identified Gap | Proposed Change |
|---|---|---|---|
| Programming and DSA | Covered through existing courses | More applied engineering practice | Retain core subjects and strengthen practical work |
| Git and testing | Not explicit in course titles | Limited visible coverage | Update Software Engineering and Industry Coding Practice |
| REST APIs | Web Technologies is available | API engineering needs greater emphasis | Rename and update Web Technologies |
| Cloud and containers | Cloud Computing is available | Hands-on deployment needs strengthening | Add Docker and Kubernetes labs |
| Machine Learning and LLMs | Machine Learning is available | Modern LLM applications need additional coverage | Update Machine Learning and add LLM Applications |
| AI-assisted development | No dedicated course identified | Verification and responsible AI workflows | Add AI-Assisted Engineering Lab |
| Responsible AI | No dedicated course identified | Ethics, privacy, and AI accountability | Add Responsible AI and Technology Ethics |

### Overall Conclusion

The curriculum already provides a foundation in programming, algorithms, databases, operating systems, networking, and machine learning. The main opportunity is to complement these subjects with practical software engineering, cloud deployment, API development, and responsible AI-assisted development.

The proposed changes aim to address these gaps while retaining core computer science subjects and maintaining the overall programme credit target. The analysis is based on the selected job descriptions and course titles; detailed syllabi and employer requirements should be checked before finalising the redesign.
